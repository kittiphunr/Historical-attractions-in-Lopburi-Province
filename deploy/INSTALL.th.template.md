# ติดตั้งเว็บ "ลพบุรี · เมืองสามยุค" ลงโฮสต์จริง

ชุดนี้สร้างสำหรับที่อยู่ **{{SITE}}** (canonical, sitemap, hreflang และภาพแชร์ลิงก์ถูกตั้งไว้ที่ที่อยู่นี้แล้ว)

เว็บเป็นไฟล์สถิตล้วน (HTML + CSS + JavaScript + ภาพ + โมเดล 3 มิติ) **ไม่ต้องใช้ PHP ฐานข้อมูล หรือ Node.js บนโฮสต์** โฮสติ้งทั่วไปรองรับ ขนาดรวมประมาณ {{SIZE}} (ส่วนใหญ่เป็นโมเดล 3 มิติ)

## ในชุดนี้มีอะไร

```
site/                  ← โฟลเดอร์เว็บทั้งหมด (อัปโหลดเนื้อหาข้างในทั้งหมด)
  index.html, privacy.html, 404.html, sitemap.xml, robots.txt
  en/ zh/ ja/          ← ฉบับภาษาอังกฤษ จีน ญี่ปุ่น (ไทยอยู่ที่ราก)
  places/              ← หน้าสถานที่ภาษาไทย
  assets/              ← สไตล์ สคริปต์ ภาพ โมเดล 3 มิติ
  .htaccess            ← ตั้งค่าสำหรับ Apache/LiteSpeed (ไฟล์ซ่อน!)
nginx.conf.example     ← ตั้งค่าสำหรับ nginx (ถ้าใช้ VPS)
INSTALL.th.md          ← ไฟล์นี้
```

## วิธีที่ 1: โฮสติ้งทั่วไป (cPanel / DirectAdmin / Plesk) — แนะนำสำหรับคนไม่ถนัดเซิร์ฟเวอร์

1. เข้าแผงควบคุมโฮสต์ → **File Manager** → เปิดโฟลเดอร์ของโดเมน (cPanel ปกติคือ `public_html`)
2. กดตั้งค่า (Settings) ติ๊ก **Show Hidden Files (dotfiles)** เพื่อให้เห็นไฟล์ `.htaccess`
3. อัปโหลดไฟล์ `.zip` แล้วกด **Extract** ในโฟลเดอร์ปลายทาง จากนั้นย้ายเนื้อหาใน `site/` ขึ้นมาไว้ที่รากของโฟลเดอร์โดเมน (ให้ `index.html` อยู่ติดกับ `public_html` ไม่ใช่ `public_html/site/index.html`) หรือใช้ FTP/SFTP (FileZilla) ลากเนื้อหาในโฟลเดอร์ `site` ขึ้นไป
   - อัปโหลดทั้งโฟลเดอร์ `assets` ให้ครบ ไฟล์โมเดล 3 มิติใหญ่ที่สุดราว 15 MB ถ้า FTP หลุดกลางทาง ให้อัปโหลดไฟล์ที่ขาดซ้ำ
4. เปิดใบรับรอง HTTPS ของโดเมน (ที่แผงควบคุมมักเรียก **SSL/TLS Status → Run AutoSSL** หรือ **Let's Encrypt**) แล้วเปิด **Force HTTPS** (ถ้าไม่มีตัวเลือกนี้ ให้เปิดคอมเมนต์ส่วน "บังคับ HTTPS" ใน `.htaccess`)
5. ตรวจตามรายการ "ตรวจหลังติดตั้ง" ด้านล่าง

> โดเมนต้องชี้ (DNS A record) มาที่โฮสต์ก่อน ปกติผู้ให้บริการโฮสต์ตั้งให้เมื่อจดโดเมนกับเขา ถ้าจดโดเมนที่อื่น ต้องไปตั้ง A record หรือ Nameserver ตามที่โฮสต์แจ้ง

## วิธีที่ 2: VPS / เซิร์ฟเวอร์ของตัวเอง (nginx)

```bash
# บนเครื่องคุณ: ส่งไฟล์ขึ้นเซิร์ฟเวอร์
rsync -avz --delete site/ user@server:/var/www/{{HOST}}/site/

# บนเซิร์ฟเวอร์: วางไฟล์ตั้งค่า แก้ path ถ้าจำเป็น แล้วโหลดใหม่
sudo cp nginx.conf.example /etc/nginx/conf.d/{{HOST}}.conf
sudo nginx -t && sudo systemctl reload nginx

# ออกใบรับรอง HTTPS ฟรี
sudo certbot --nginx -d {{HOST}} -d www.{{HOST}}
```

## วิธีที่ 3: บริการโฮสต์เว็บสถิต (Netlify / Cloudflare Pages / Vercel)

ลากโฟลเดอร์ `site` ไปวางหน้าอัปโหลดของบริการนั้น แล้วผูกโดเมน {{HOST}} ตามขั้นตอนของบริการ (HTTPS ให้อัตโนมัติ) หน้า 404 (`404.html`) ใช้งานได้เองในบริการเหล่านี้ ไม่ต้องใช้ไฟล์ `.htaccess` หรือ `nginx.conf.example`

## ตรวจหลังติดตั้ง

เปิดที่อยู่เหล่านี้แล้วตรวจว่าใช้ได้:

| ที่อยู่ | ควรเห็น |
|---|---|
| {{SITE}} | หน้าแรกภาษาไทย แบนเนอร์และตราจังหวัด สภาพอากาศ |
| {{SITE}}en/ | หน้าแรกภาษาอังกฤษ (เช่นเดียวกับ `zh/` และ `ja/`) |
| {{SITE}}places/sam-yot.html | หน้าพระปรางค์สามยอด กดภาพปกแล้วเห็นโมเดล 3 มิติ |
| {{SITE}}privacy.html | นโยบายความเป็นส่วนตัว |
| {{SITE}}sitemap.xml | ไฟล์ XML รายการหน้าทั้งหมด (48 ที่อยู่) |
| {{SITE}}หน้าที่ไม่มีอยู่ | หน้า 404 ของเว็บ (ไม่ใช่หน้า 404 ธรรมดาของโฮสต์) |

และลองบนมือถือ: กดปุ่ม "ดูแบบ AR" ในหน้าสถานที่ (ใช้ได้เฉพาะเมื่อเปิดด้วย **https://**)

## หลังติดตั้ง

1. **Google Search Console** (https://search.google.com/search-console): เพิ่มเว็บ {{SITE}} ยืนยันความเป็นเจ้าของ แล้วส่ง sitemap `{{SITE}}sitemap.xml` (เว็บมีหน้าแยก 4 ภาษาพร้อม hreflang) ทำเช่นเดียวกันที่ Bing Webmaster Tools ได้
2. **สมุดเยี่ยมและรีวิวแบบแชร์ร่วมกัน:** ตอนนี้ข้อความที่ผู้เข้าชมเขียนเก็บไว้ในเบราว์เซอร์ของแต่ละคน (ไม่มีใครเห็นของคนอื่น) ถ้าโฮสต์ของคุณมี PHP + MySQL ขอชุดแบบ PHP (`--php`) ซึ่งมีสมุดเยี่ยมและรีวิวสถานที่ (รอผู้ดูแลอนุมัติ) พร้อมหน้าผู้ดูแล ดูคู่มือ `INSTALL.php.th.md` ในชุดนั้น หรือติดตั้ง API สมุดเยี่ยมบน Cloudflare (ฟรี ใช้เวลาประมาณ 10 นาที ดูขั้นตอนใน `backend/cloudflare/README.md` ของโปรเจกต์) แล้ว
   - ใส่ที่อยู่ API ในไฟล์ `assets/js/config.js` บนโฮสต์ (บรรทัด `guestbookApi: '...'`)
   - เพิ่ม `{{SITE_ORIGIN}}` ใน `ALLOWED_ORIGINS` ของ `backend/cloudflare/wrangler.toml` แล้วรัน `npx wrangler deploy` ใหม่ (ไม่เช่นนั้นเบราว์เซอร์จะปฏิเสธ)
3. **นโยบายความเป็นส่วนตัว:** หน้านี้ระบุผู้ให้บริการโฮสติ้งแบบกว้าง ๆ และช่องทางติดต่อเป็นหน้า Issues บน GitHub ของโปรเจกต์ ถ้าต้องการใส่อีเมลหรือช่องทางติดต่อของคุณ แจ้งผู้ดูแลโปรเจกต์เพื่อสร้างชุดไฟล์ใหม่ (แก้ที่ `contact.email` ใน `content/privacy.json`)
4. **ตราประจำจังหวัด:** ใช้เพื่อประกอบเนื้อหา สิทธิ์เป็นของหน่วยงานเจ้าของตรา เว็บนี้ไม่ใช่เว็บไซต์ทางการของจังหวัดลพบุรี (มีข้อความระบุในเว็บแล้ว) ถ้าใช้เชิงพาณิชย์หรือเป็นทางการ ควรขออนุญาตก่อน

## อัปเดตเว็บภายหลัง

แก้โปรเจกต์แล้วสร้างชุดไฟล์ใหม่ด้วยคำสั่ง (ต้องมี Node.js):

```bash
npm install
npm run build
node tools/package-site.mjs --site {{SITE}}
```

จะได้โฟลเดอร์ `dist/site` และไฟล์ zip ใหม่ อัปโหลดทับของเดิม (เฉพาะไฟล์ที่เปลี่ยนก็พอ) ภาพ/โมเดลถูกแคชในเบราว์เซอร์ผู้ชมได้ถึง 7 วัน ถ้าเปลี่ยนไฟล์ภาพหรือโมเดลเดิม ให้ตั้งชื่อไฟล์ใหม่ หรือให้ผู้ชมรีเฟรชแบบล้างแคช

## แก้ปัญหาเบื้องต้น

- **หน้าแรกขึ้นแต่รูปไม่ขึ้น/สไตล์เพี้ยน:** โฟลเดอร์ `assets` ขึ้นไม่ครบ หรือวางซ้อนโฟลเดอร์ (ต้องเป็น `{{SITE}}assets/tailwind.css` เปิดได้)
- **ทุกหน้าย่อย 404:** ไฟล์ `places/` `en/` `zh/` `ja/` ยังไม่ได้อัปโหลด หรือโฮสต์เป็นระบบที่แยกตัวพิมพ์เล็กใหญ่ (ชื่อไฟล์ในชุดเป็นตัวพิมพ์เล็กทั้งหมด อย่าเปลี่ยนชื่อ)
- **หน้า 404 เป็นของโฮสต์ ไม่ใช่ของเรา:** ไม่พบไฟล์ `.htaccess` (ไฟล์ซ่อนหายตอนอัปโหลด) หรือโฮสต์ไม่ใช้ Apache ให้ตั้ง error page 404 เป็น `404.html` ในแผงควบคุม
- **AR ไม่ขึ้น:** ต้องเปิดผ่าน https:// ด้วยมือถือที่รองรับ (Android + Chrome พร้อม Google Play Services for AR, หรือ iPhone/iPad + Safari)
- **โมเดล 3 มิติไม่ขึ้นหลังกดภาพปก:** เปิด Developer Tools ดูว่าไฟล์ `assets/js/three-scenes.js` และไฟล์ `.glb` โหลดได้ (200) หรือไม่ ไฟล์ที่ขาดมักเกิดจากอัปโหลดไม่ครบ
