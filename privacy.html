    Privacy

    นโยบายความเป็นส่วนตัว

    ปรับปรุงล่าสุด: 21 พฤศจิกายน 2569

    เว็บไซต์นี้รวบรวมข้อมูลแหล่งท่องเที่ยวประวัติศาสตร์จังหวัดลพบุรีเพื่อการศึกษาและการท่องเที่ยว ไม่ใช่เว็บไซต์ทางการของจังหวัด เราเก็บข้อมูลส่วนบุคคลให้น้อยที่สุด ไม่มีระบบสมัครสมาชิก ไม่มีโฆษณา และไม่ใช้เครื่องมือวิเคราะห์หรือติดตามพฤติกรรมผู้เข้าชม

    01ผู้ดูแลเว็บไซต์

    เว็บไซต์นี้ดูแลโดยเจ้าของโปรเจกต์ (Kittiphun Ruttanakorn) ซึ่งเป็นผู้ควบคุมข้อมูลส่วนบุคคลตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA) สำหรับข้อมูลที่เก็บผ่านสมุดเยี่ยมของเว็บนี้

    02ข้อมูลที่เราเก็บและวัตถุประสงค์

    สมุดเยี่ยมและรีวิว: เมื่อคุณเขียนข้อความหรือรีวิว เราเก็บชื่อที่คุณกรอก ข้อความ คะแนนดาวและสถานที่ที่เลือก (ถ้ามี) และเวลาที่ส่ง เพื่อแสดงในสมุดเยี่ยมหรือหน้าสถานที่ให้ผู้เข้าชมทุกคนเห็น (รีวิวแสดงหลังผู้ดูแลตรวจสอบ) ข้อมูลเหล่านี้เป็นข้อมูลสาธารณะ กรุณาอย่าใส่ข้อมูลส่วนตัว เช่น เบอร์โทรหรืออีเมล

    การป้องกันสแปม: เมื่อเปิดใช้สมุดเยี่ยมแบบแชร์ร่วมกัน ระบบจะเก็บค่าแฮชของที่อยู่ IP (ผ่านการเข้ารหัสทางเดียวแบบ SHA-256 ผสมรหัสลับ และตัดให้สั้น) ไว้กับข้อความ เพื่อจำกัดจำนวนข้อความต่อคนเท่านั้น เราไม่เก็บที่อยู่ IP จริง และไม่สามารถย้อนกลับจากค่าแฮชไปเป็นที่อยู่ IP ได้ ก่อนส่งข้อความ เบราว์เซอร์จะคำนวณโจทย์ยืนยันตัวตนเล็กน้อยโดยอัตโนมัติ (CAPTCHA แบบ proof-of-work) โดยไม่เก็บข้อมูลเพิ่มและไม่ส่งข้อมูลไปบริการภายนอก ยกเว้นเจ้าของเว็บเลือกใช้ Cloudflare Turnstile ซึ่งจะส่งข้อมูลการใช้งานเบราว์เซอร์และ IP ไปยัง Cloudflare เพื่อตรวจว่าเป็นคนจริง ถ้าเจ้าของเว็บเปิดการแจ้งเตือน รีวิวหรือข้อความใหม่ (ชื่อที่แสดงและข้อความ) จะถูกส่งทางอีเมลถึงเจ้าของเว็บผ่านระบบอีเมลของโฮสต์ เพื่อให้ตรวจสอบก่อนอนุมัติ

    ข้อมูลในเบราว์เซอร์ของคุณ: เว็บเก็บค่าที่คุณเลือกไว้ในเบราว์เซอร์ของคุณเอง (localStorage/sessionStorage) ได้แก่ โหมดกลางวัน/กลางคืน ภาษา และตัวบอกสถานะระหว่างเปลี่ยนหน้า รวมถึงข้อความสมุดเยี่ยมของคุณเมื่อยังไม่ได้เปิดสมุดเยี่ยมแบบแชร์ร่วมกัน ข้อมูลเหล่านี้อยู่ในอุปกรณ์ของคุณและไม่ถูกส่งให้เรา คุณลบได้โดยล้างข้อมูลเว็บไซต์ในเบราว์เซอร์ เว็บนี้ไม่ตั้งคุกกี้เอง

    03บริการของบุคคลที่สาม

    เมื่อคุณเปิดเว็บนี้ เบราว์เซอร์ของคุณเชื่อมต่อกับบริการภายนอกตามด้านล่าง ซึ่งอาจเห็นที่อยู่ IP และข้อมูลเบราว์เซอร์ของคุณตามนโยบายของผู้ให้บริการนั้น เราไม่ได้ควบคุมข้อมูลที่บริการเหล่านั้นเก็บ

    • GitHub Pages — ผู้ให้บริการโฮสต์เว็บไซต์ (GitHub, Inc.)
    • Google Fonts — ฟอนต์ Prompt (Google LLC)
    • Open-Meteo.com — ข้อมูลสภาพอากาศ เบราว์เซอร์ของคุณส่งเฉพาะพิกัดตัวเมืองลพบุรี ไม่ส่งตำแหน่งของคุณ
    • ฐานข้อมูลสมุดเยี่ยมและรีวิว — เก็บและแสดงข้อความ ทำงานบนฐานข้อมูล MySQL ของโฮสต์เว็บไซต์ หรือบน Cloudflare Workers/D1 (Cloudflare, Inc.) เฉพาะเมื่อเจ้าของเว็บเปิดใช้งาน
    • YouTube และ Google Maps — มีเฉพาะลิงก์ที่เปิดในแท็บใหม่เมื่อคุณกดเท่านั้น ถ้าอนาคตมีการฝังวิดีโอ จะใช้โดเมน youtube-nocookie.com

    04โมเดล 3 มิติและ AR

    โมเดล 3 มิติแสดงผลในเบราว์เซอร์ของคุณ ไม่มีการส่งข้อมูลส่วนตัวออกไป เมื่อกด “ดูแบบ AR” อุปกรณ์ของคุณจะเปิดตัวแสดง AR ของระบบ (เช่น WebXR, Scene Viewer ของ Google หรือ Quick Look ของ Apple) ซึ่งขอใช้กล้องบนอุปกรณ์ของคุณเอง ภาพจากกล้องไม่ถูกส่งมายังเว็บไซต์นี้

    05การเก็บรักษาและการลบข้อมูล

    ข้อความสมุดเยี่ยมและรีวิวบนเซิร์ฟเวอร์เก็บไว้จนกว่าผู้ดูแลจะลบ (ตามคำขอหรือเพราะไม่เหมาะสม) รีวิวที่ไม่ผ่านการตรวจสอบอาจถูกลบ ส่วนระบบ Cloudflare เก็บไม่เกิน 2,000 ข้อความล่าสุดและลบรายการเก่าอัตโนมัติ ข้อความที่เก็บในเบราว์เซอร์ของคุณอยู่จนกว่าคุณจะล้างข้อมูลเว็บไซต์

    06สิทธิของคุณ

    ตาม PDPA คุณมีสิทธิขอเข้าถึงและขอรับสำเนา ขอแก้ไขให้ถูกต้อง ขอให้ลบหรือทำลาย ขอให้ระงับการใช้ คัดค้านการเก็บ ใช้ หรือเปิดเผยข้อมูลของคุณ และถอนความยินยอมเมื่อใดก็ได้ รวมถึงร้องเรียนต่อสำนักงานคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล หากต้องการให้ลบข้อความของคุณออกจากสมุดเยี่ยม โปรดแจ้งชื่อที่ใช้และเนื้อหาข้อความตามช่องทางด้านล่าง เนื่องจากเราไม่ได้เก็บข้อมูลที่ใช้ระบุตัวตนอื่นนอกจากที่คุณกรอก

    07เด็กและเยาวชน

    เว็บไซต์นี้ไม่ได้มุ่งเก็บข้อมูลจากเด็ก หากผู้ปกครองพบว่าเด็กเขียนข้อมูลส่วนตัวในสมุดเยี่ยม โปรดแจ้งเราเพื่อลบข้อความนั้น

    08การเปลี่ยนแปลงนโยบาย

    หากมีการเปลี่ยนแปลงวิธีเก็บหรือใช้ข้อมูล เราจะปรับหน้านี้และแก้วันที่ปรับปรุงล่าสุดด้านบน

    ติดต่อเรา

    ติดต่อเรื่องข้อมูลส่วนบุคคลหรือขอลบข้อความได้ที่หน้า Issues ของโปรเจกต์บน GitHub (หน้านี้เป็นสาธารณะ จึงโปรดอย่าใส่ข้อมูลส่วนตัว ระบุเพียงชื่อที่ใช้และเนื้อหาข้อความที่ต้องการลบ)
