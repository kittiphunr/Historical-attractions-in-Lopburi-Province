    Privacy

    隐私政策

    最后更新：2026 年 11 月 21 日（佛历 2569）

    本网站汇集华富里府历史景点的信息，用于教育和旅游，并非该府官方网站。我们尽量少收集个人数据：没有注册系统，没有广告，也不使用分析或跟踪工具。

    01网站运营者

    本网站由项目所有者（Kittiphun Ruttanakorn）运营。对于通过本站留言簿收集的数据，其为泰国《个人数据保护法》（佛历 2562，PDPA）下的数据控制者。

    02我们收集的数据及目的

    留言簿：当您留言时，我们会保存您填写的姓名、留言内容、所选的星级和景点（如有）以及提交时间，并向所有访客展示。这些信息是公开的，请不要填写电话或邮箱等个人信息。

    垃圾信息防护：启用共享留言簿时，系统会将您 IP 地址的哈希值（使用加密盐的单向 SHA-256 并截短）与留言一起保存，仅用于限制每人发送的留言数量。我们不保存真实 IP 地址，且无法从哈希值还原出 IP 地址。

    浏览器中的数据：本站将您的选择保存在您自己的浏览器中（localStorage/sessionStorage），包括日/夜模式、语言、页面切换标记，以及在未启用共享留言簿时您的留言。这些数据保留在您的设备上，不会发送给我们。您可以通过清除浏览器中的网站数据来删除。本站自身不设置 Cookie。

    03第三方服务

    打开本站时，您的浏览器会连接下列外部服务，这些服务可能按各自的政策看到您的 IP 地址和浏览器信息。我们无法控制它们收集的数据。

    • GitHub Pages — 网站托管服务（GitHub, Inc.）
    • Google Fonts — Prompt 字体（Google LLC）
    • Open-Meteo.com — 天气数据。您的浏览器仅发送华富里市区的坐标，不发送您自己的位置。
    • Cloudflare Workers/D1 — 用于保存和显示共享留言簿，仅在网站所有者启用时使用（Cloudflare, Inc.）
    • YouTube 和 Google 地图 — 仅为您点击后在新标签页打开的链接。若将来嵌入视频，将使用 youtube-nocookie.com 域名。

    043D 模型与 AR

    3D 模型在您的浏览器中渲染，不会发送任何个人数据。点击“AR 查看”时，您的设备会打开系统自带的 AR 查看器（如 WebXR、Google Scene Viewer 或 Apple Quick Look），并请求使用设备摄像头。摄像头画面不会发送到本网站。

    05保存期限与删除

    服务器上的留言最多保留最近 2,000 条，更早的会被自动删除；也可能因您的请求或内容不当而被网站所有者提前删除。保存在您浏览器中的留言会一直保留，直到您清除网站数据。

    06您的权利

    根据 PDPA，您有权申请访问并获取数据副本、要求更正、要求删除或销毁、要求限制使用、反对收集、使用或披露，并可随时撤回同意，也可向个人数据保护委员会投诉。如需从留言簿中删除您的留言，请通过下方渠道告知您使用的姓名和留言内容，因为除您填写的信息外，我们不保存其他可识别身份的信息。

    07儿童

    本网站并非为收集儿童数据而设。如家长发现孩子在留言簿中写下了个人信息，请告知我们以便删除该留言。

    08政策变更

    如数据收集或使用方式发生变化，我们将更新本页面及上方日期。

    联系我们

    如有个人数据方面的问题或需要删除留言，请使用本项目在 GitHub 上的 Issues 页面（该页面是公开的，请勿发布个人信息，仅说明所用姓名和需要删除的留言内容）。

      图片和视频政策： 本网站不会在未注明来源的情况下嵌入他人的照片或视频。每张实拍照片都会在图下标明摄影师、许可协议和原始链接；视频则显示频道名称并链接到版权方 YouTube。

      首页封面图： 由项目所有者提供的全景拼合图（三塔寺、水边铁路、红顶白色建筑）。该图由多个部分合成，各部分的摄影者或创作者及授权许可尚不明确，因此仅注明由项目所有者提供。若了解来源，将在此补充致谢。

      AR: 使用 <model-viewer> （Google，Apache-2.0），支持 Android Chrome 的 WebXR、Scene Viewer 以及 iPhone/iPad 的 Quick Look。需要 HTTPS 和支持 AR 的设备。
