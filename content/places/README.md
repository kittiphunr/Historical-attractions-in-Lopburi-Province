# เพิ่มรูปภาพและข้อมูลของแต่ละสถานที่

# ข้อมูลของแต่ละสถานที่ (ไฟล์เดียวต่อสถานที่)

ข้อมูลทั้งหมดของสถานที่หนึ่งแห่ง — เนื้อหาไทย คำแปล en/zh/ja รูป และหัวข้อเพิ่มเติม — อยู่ในไฟล์เดียว `content/places/<id>.json` แล้ว `npm run build` สร้างหน้าเว็บ (`places/<id>.html`, `en|zh|ja/`), `assets/js/data.js`, แพ็กภาษา และ sitemap ให้เอง

**อย่าแก้ `assets/js/data.js` ตรง ๆ** — เป็นไฟล์สร้างอัตโนมัติ (แก้สถานที่ที่ไฟล์ place · แก้ส่วนที่ไม่ใช่สถานที่ เช่น แหล่งอ้างอิงกลาง ไทม์ไลน์ เส้นทาง หมุดแผนที่ 3 มิติ ที่ `content/data.template.js`)

## ขั้นตอนทำงาน

```bash
npm run new-place -- wat-example --name "วัดตัวอย่าง" --en "Wat Example" --era khmer   # สร้างไฟล์จากแม่แบบ (เลขลำดับถัดไปให้เอง)
# เปิด content/places/wat-example.json กรอก place (ไทย) และ translations (en/zh/ja)
npm run check     # ตรวจความครบถ้วน: ฟิลด์ที่ต้องมี · ไฟล์โมเดล/โปสเตอร์/ภาพแชร์มีจริง · เครดิตรูป · คำแปลที่ขาด
npm run build     # สร้างทุกอย่าง
```

ส่วนในไฟล์: `place` = เนื้อหาไทย (ต้นฉบับ) · `translations.en|zh|ja` = คำแปลของข้อความไทยแต่ละข้อความใน `place` (คีย์ต้องตรงตัวอักษรกับข้อความไทย — `npm run check` เตือนถ้าแก้ไทยแล้วคีย์ไม่ตรง) · `gallery`, `sections`, `facts` = รูปและหัวข้อเพิ่มเติม (ด้านล่าง) · `sourceDefs` (ไม่บังคับ) = แหล่งอ้างอิงที่ใช้เฉพาะสถานที่นี้ `{ "id", "name", "url" }`

`npm run check` ออกรหัส 1 เมื่อมีข้อผิดพลาด (ไฟล์อ้างถึงแต่ไม่มี · รูปไม่ระบุผู้ถ่าย/สัญญาอนุญาต · หมายเลขซ้ำ ฯลฯ) ส่วนคำเตือน (ยังไม่มีหมุดแผนที่/โมเดล/คำแปล) ไม่ทำให้ล้ม

`<id>` คือ `sam-yot`, `sala-phra-kan`, `narai-palace`, `wat-lai`, `mahathat`, `wichayen`, `khao-wong`, `prang-khaek`, `sao-thong-thong`, `nakhon-kosa`, `kawisararam`, `ang-sap-lek`, `sap-champa`

## วิธีเพิ่มรูป

1. วางไฟล์ภาพใน `assets/places/<id>/` (แนะนำ `.webp` หรือ `.jpg` กว้างไม่เกิน 1600 px, ไม่เกิน ~300 KB ต่อภาพ)
2. เพิ่มรายการใน `gallery` ของ `content/places/<id>.json` (ภาพแรกจะแสดงใหญ่ที่สุด)
3. รัน `npm run build:places` (หรือ `npm run build`) แล้ว commit

```json
{
  "gallery": [
    {
      "src": "front.webp",
      "alt": "มุมมองด้านหน้าพระปรางค์สามยอดตอนเช้า",
      "caption": "ด้านหน้าตอนเช้า",
      "author": "ชื่อผู้ถ่ายภาพ",
      "license": "CC BY-SA 4.0",
      "licenseUrl": "https://creativecommons.org/licenses/by-sa/4.0/",
      "sourceUrl": "https://ลิงก์ต้นทางของภาพ"
    }
  ]
}
```

- `src` เป็นชื่อไฟล์ใน `assets/places/<id>/` (หรือ URL เต็ม)
- `alt` คำอธิบายภาพสำหรับผู้ใช้โปรแกรมอ่านหน้าจอ (ควรใส่ทุกภาพ)
- ถ้าเป็นภาพของคุณเอง ใส่ `"author": "ชื่อคุณ"` และ `"license": "ภาพถ่ายโดยเจ้าของเว็บไซต์"` ได้ ไม่ต้องมี `licenseUrl`/`sourceUrl`
- **ภาพที่นำมาจากที่อื่นต้องระบุผู้ถ่าย สัญญาอนุญาต และลิงก์ต้นทางเสมอ** (ภาพจาก Wikimedia Commons ดูได้จากหน้าไฟล์ภาพ)

รูปใน `gallery` และ `sections[].images` กดแล้วขยายเป็นภาพใหญ่ (lightbox) พร้อมคำบรรยายและเครดิต เลื่อนดูภาพถัดไปได้ด้วยปุ่ม ลูกศรซ้าย/ขวา หรือปัดบนมือถือ ซูมได้ด้วยปุ่ม +/−, ล้อเมาส์, บีบสองนิ้ว หรือดับเบิลคลิก/แตะสองครั้ง แล้วลากเพื่อเลื่อนดู (ภาพที่ใหญ่ขึ้นจะคมชัดตามความละเอียดของไฟล์ที่ใส่) กด Esc เพื่อปิด

## วิธีเพิ่มหัวข้อ/ข้อมูล

`sections` คือหัวข้อเพิ่มเติม แสดงต่อจาก "เตรียมตัวไป" ก่อนแหล่งอ้างอิง:

```json
{
  "sections": [
    {
      "title": "การเดินทางและเวลาเปิด",
      "body": ["ย่อหน้าที่ 1", "ย่อหน้าที่ 2"],
      "bullets": ["ข้อสั้น ๆ ข้อที่ 1", "ข้อที่ 2"],
      "images": [{ "src": "map.webp", "alt": "…", "caption": "…", "author": "…", "license": "…" }]
    }
  ],
  "facts": [["ค่าเข้าชม", "ฟรี"], ["เวลาเปิด", "08.30–16.30 น."]]
}
```

- `body` และ `bullets` ใส่อย่างใดอย่างหนึ่งหรือทั้งสองก็ได้, `images` ไม่บังคับ
- `facts` เพิ่มช่องข้อมูลสั้น ๆ ต่อท้ายช่อง "สมัย/ผู้สร้าง/…" ที่มีอยู่

## เรื่องภาษา

คำแปลของข้อความใน `place` ใส่ที่ `translations` ของไฟล์เดียวกัน รูปแบบ `"ข้อความไทย": "คำแปล"` ตรงตัวอักษรทุกตัว (ขอให้ผู้ช่วยแปลให้ได้) ข้อความที่ใช้ซ้ำหลายหน้า (เช่น ชื่อยุค) อยู่ในพจนานุกรมกลาง `i18n/<code>.json` ซึ่งถูกรวมกันตอน build — คำแปลในไฟล์สถานที่ทับค่ากลาง
