# เพิ่มรูปภาพและข้อมูลของแต่ละสถานที่

หน้าของแต่ละสถานที่ (`places/<id>.html`) ถูกสร้างอัตโนมัติจาก 2 แหล่ง:

1. `assets/js/data.js` — ข้อมูลหลัก (ชื่อ ประวัติ สถาปัตยกรรม ไฮไลต์ เตรียมตัวไป แหล่งอ้างอิง วิดีโอ)
2. **ไฟล์ในโฟลเดอร์นี้** `content/places/<id>.json` — รูปภาพและหัวข้อเพิ่มเติมที่คุณเติมเอง (ไม่ต้องแตะโค้ด)

`<id>` คือ `sam-yot`, `sala-phra-kan`, `narai-palace`, `wat-lai`, `mahathat`, `wichayen`, `khao-wong`, `prang-khaek`, `sao-thong-thong`, `nakhon-kosa`

## วิธีเพิ่มรูป

1. วางไฟล์ภาพใน `assets/places/<id>/` (แนะนำ `.webp` หรือ `.jpg` กว้างไม่เกิน 1600 px, ไม่เกิน ~300 KB ต่อภาพ)
2. เพิ่มรายการใน `gallery` ของ `content/places/<id>.json` (ภาพแรกจะแสดงใหญ่ที่สุด)
3. รัน `npm run build:places` (หรือ `npm run build`) แล้ว commit

```json
{
  "gallery": [
    {
      "src": "front.webp",
      "alt": "มุมมองด้านหน้าพระปรางค์สามยอดตอนเช้า",
      "caption": "ด้านหน้าตอนเช้า",
      "author": "ชื่อผู้ถ่ายภาพ",
      "license": "CC BY-SA 4.0",
      "licenseUrl": "https://creativecommons.org/licenses/by-sa/4.0/",
      "sourceUrl": "https://ลิงก์ต้นทางของภาพ"
    }
  ]
}
```

- `src` เป็นชื่อไฟล์ใน `assets/places/<id>/` (หรือ URL เต็ม)
- `alt` คำอธิบายภาพสำหรับผู้ใช้โปรแกรมอ่านหน้าจอ (ควรใส่ทุกภาพ)
- ถ้าเป็นภาพของคุณเอง ใส่ `"author": "ชื่อคุณ"` และ `"license": "ภาพถ่ายโดยเจ้าของเว็บไซต์"` ได้ ไม่ต้องมี `licenseUrl`/`sourceUrl`
- **ภาพที่นำมาจากที่อื่นต้องระบุผู้ถ่าย สัญญาอนุญาต และลิงก์ต้นทางเสมอ** (ภาพจาก Wikimedia Commons ดูได้จากหน้าไฟล์ภาพ)

รูปใน `gallery` และ `sections[].images` กดแล้วขยายเป็นภาพใหญ่ (lightbox) พร้อมคำบรรยายและเครดิต เลื่อนดูภาพถัดไปได้ด้วยปุ่ม ลูกศรซ้าย/ขวา หรือปัดบนมือถือ กด Esc เพื่อปิด

## วิธีเพิ่มหัวข้อ/ข้อมูล

`sections` คือหัวข้อเพิ่มเติม แสดงต่อจาก "เตรียมตัวไป" ก่อนแหล่งอ้างอิง:

```json
{
  "sections": [
    {
      "title": "การเดินทางและเวลาเปิด",
      "body": ["ย่อหน้าที่ 1", "ย่อหน้าที่ 2"],
      "bullets": ["ข้อสั้น ๆ ข้อที่ 1", "ข้อที่ 2"],
      "images": [{ "src": "map.webp", "alt": "…", "caption": "…", "author": "…", "license": "…" }]
    }
  ],
  "facts": [["ค่าเข้าชม", "ฟรี"], ["เวลาเปิด", "08.30–16.30 น."]]
}
```

- `body` และ `bullets` ใส่อย่างใดอย่างหนึ่งหรือทั้งสองก็ได้, `images` ไม่บังคับ
- `facts` เพิ่มช่องข้อมูลสั้น ๆ ต่อท้ายช่อง "สมัย/ผู้สร้าง/…" ที่มีอยู่

## เรื่องภาษา

ข้อความที่เพิ่มในไฟล์นี้เป็นภาษาไทย ถ้าสลับเว็บเป็นอังกฤษ/จีน/ญี่ปุ่นจะยังแสดงภาษาไทยจนกว่าจะเพิ่มคำแปลใน `i18n/en.json`, `zh.json`, `ja.json` (รูปแบบ `"ข้อความไทย": "คำแปล"` ตรงตัวอักษรทุกตัว) แล้วรัน `npm run build:lang` — ขอให้ผู้ช่วยแปลให้ได้
